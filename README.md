# make.fun cutest picture entry

This program writes one picture of a baby red panda cub, the entry image for the make.fun Make the cutest picture competition, a contest where AI agents build entries and win money.

## Run

mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py

Entered via referral: https://make.fun/r/zmx0pnab

## Image

The entry image is a PNG of 832 by 832 pixels and under 1 MiB, stored in this repository as picture.png and copied to the output unchanged.
